# z80-python 0.3.0

Version 0.3.0 is the first complete public release of the readable, pure-Python,
SingleStep-complete and ZEX-certified reference core together with its processor
inspection toolkit.

## Core and lifecycle

- Include host-controlled RESET, NMI, maskable interrupts, EI delay, RETN, and
  HALT as deterministic instruction-boundary contracts.
- Preserve the zero-runtime-dependency, ordinary-Python execution core.
- Retain full validation against 1,604,000 SingleStepTests transitions and
  ZEXDOC/ZEXALL under CPython and PyPy.

## Learning and inspection

- Add immutable, validated `CPUState` capture and restoration.
- Add complete structured disassembly for every opcode form supported by the
  core, using an explicit side-effect-free reader.
- Add `DebugSession` with bounded execution, execute breakpoints, lifecycle-aware
  records, T-state totals, and bounded history.
- Add the dependency-free `CommandDebugger` text frontend.

## Advanced diagnostics

- Add incremental, field-level first-divergence analysis for processor traces.
- Add bounded live lockstep comparison of two debug sessions.
- Add strict, deterministic, versioned JSON Lines trace persistence that streams
  without buffering complete runs.
- Prove causal diagnosis in Galemu by locating the exact vblank scheduler boundary
  where two otherwise identical machines first differed.

## API hardening

- Ship a PEP 561 `py.typed` marker.
- Make `DebugTarget` a runtime-checkable structural protocol.
- Validate public immutable debugger and trace values at construction.
- Document semantic-versioning guarantees and public/private boundaries.
- Install and exercise the built wheel in CI rather than validating only a source
  checkout.

## Development provenance

The project was developed with extensive AI assistance—vibe coded in the
colloquial sense—but its correctness claim rests on independent vectors, ZEX CRC
exercisers, focused regression tests, and real emulator integration evidence.
